# Amreshwar Maravi — Interactive Portfolio

A modern, high-performance portfolio featuring a scroll-driven canvas engine, cinematic crimson & obsidian aesthetic, GPU WebGL chroma keying, and interactive micro-animations.

---

## ✨ Features

- **Cinematic Scroll Animation**: 240-frame high-resolution sequence rendered on an HTML5 canvas with GPU-accelerated WebGL chroma keying and inertia LERP smoothing.
- **Behind-the-Character Typography**: Massive red `PORTFOLIO` display title seamlessly layered behind the character's head and sunglasses.
- **Selected Works**: Showcase of featured client projects (*Veloce Bikes*, *Woodcraft*, *Urbanic Fashion*).
- **Education & Skills**: Curated skill tags and interactive 5-step work process timeline.
- **Responsive Architecture**: Fully responsive layout tailored for ultra-wide displays down to mobile screens.
- **Contact & Footer**: Direct email CTA, contact info, social links, and an interactive back-to-top button.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS**: Custom modern design system with glassmorphism, responsive grid layouts, and custom typography.
- **JavaScript (ES6+)**: Custom canvas scrubbing engine, WebGL shaders for real-time background subtraction, and keyframe preloading queue.
- **Fonts**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans), [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue), [Oswald](https://fonts.google.com/specimen/Oswald), [Caveat](https://fonts.google.com/specimen/Caveat).

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/littleb21/Amreshwar-maravi.git
   cd Amreshwar-maravi
   ```

2. Start a local HTTP server:
   - **PowerShell**:
     ```powershell
     .\server.ps1
     ```
   - **Python**:
     ```bash
     python -m http.server 8080
     ```
   - **Node / npx**:
     ```bash
     npx serve .
     ```

3. Open your browser and navigate to `http://localhost:8080/`.
